# Version 4.2 Release Notes

Link 4.2 can save and restore `⎕STOP` and `⎕TRACE` settings for linked
functions and operators in the directory configuration file. Enable the
`recordFlags` option when creating the link (for example, `-recordflags` in the
user command). See [Stop and Trace flags](Usage/ConfigFiles.md#stop-and-trace-flags)
for details.

For other differences from Link 4.0, see the [Version 4.1 Release Notes](ReleaseNotes41.md).
